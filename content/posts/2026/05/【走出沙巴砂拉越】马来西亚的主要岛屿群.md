马来西亚的海岸线长达4800公里，被马六甲海峡、安达曼海和中国南海等不同海域环绕，因此拥有众多迷人的岛屿。根据地理位置，这些岛屿通常被划分为**西马岛屿**和**东马岛屿**两大区域。

**🏝️ 西马 (Peninsular Malaysia) 主要岛屿**
这部分岛屿主要指位于马来半岛两侧海岸线上的岛屿。

| 岛屿名称 | 所属州属 | 主要特色与著名景点 |
| :--- | :--- | :--- |
| 兰卡威岛 (Langkawi) | 吉打州 (Kedah) | 由99个岛屿组成，免税岛，拥有天空之桥、Kilim Karst Geoforest Park等景点。 |
| 槟城岛 (Penang Island) | 槟城州 (Penang) | 以丰富的历史文化遗产和街头美食闻名，被联合国教科文组织列为世界文化遗产。 |
| 邦咯岛 (Pangkor) | 霹雳州 (Perak) | 以宁静的渔村和细白沙滩闻名，附近有著名的私人奢华岛屿绿中海 (Pangkor Laut)。 |
| 刁曼岛 (Tioman) | 彭亨州 (Pahang) | 位于东海岸，被认为是世界上最美的岛屿之一，是绝佳的潜水胜地。 |
| 热浪岛 (Redang) | 登嘉楼州 (Terengganu) | 同样位于东海岸，以清澈见底的海水和丰富的海洋生物著称，是海洋公园保护区。 |
| 停泊岛 (Perhentian) | 登嘉楼州 (Terengganu) | 由大小停泊岛组成，被誉为“来马来西亚必去的岛屿之一”，拥有极佳的沙滩和潜水点。 |
| 诗巫岛 (Sibu) | 柔佛州 (Johor) | 位于西马南端东海岸，也被称为“幸福岛”，是柔佛州群岛中的一员。 |

**🏝️ 东马 (East Malaysia) 主要岛屿**
这部分岛屿位于婆罗洲 (Borneo) 北部的沙巴州和砂拉越州，以及纳闽联邦直辖区。

| 岛屿名称 | 所属州属 | 主要特色与著名景点 |
| :--- | :--- | :--- |
| 诗巴丹岛 (Sipadan) | 沙巴州 (Sabah) | 世界顶级潜水胜地之一，以其独特的海底峭壁和丰富的海洋生物（如海龟、梭鱼群）闻名，被誉为“艺术品”。 |
| 马布岛 (Mabul) | 沙巴州 (Sabah) | 以其“漫潜”(Muck Diving) 闻名，是微距摄影爱好者的天堂，可发现各种罕见的小型海洋生物。 |
| 卡帕莱岛 (Kapalai) | 沙巴州 (Sabah) | 以其建于浅礁上的水上屋而闻名，环礁生态系统独特，非常适合浮潜和度假。 |
| 纳闽岛 (Labuan) | 联邦直辖区 (W.P.) | 国际离岸金融中心，也以二战历史遗迹和沉船潜水点而闻名。 |


《走出沙巴砂拉越》的故事舞台横跨马来西亚东部的沙巴州和砂拉越州。这里不仅是故事发生的地理背景，更以其独特的自然风貌和深厚文化，深度参与并内核驱动了Vera的蜕变之旅。

### 🏙️ 古晋 (Kuching)：序曲与终章的交汇点

古晋是砂拉越的首府，也是故事循环结构的枢纽，Vera在这里经历了从初来乍到的考验到最后带着回忆离开的全过程。这座城市的名字在马来语中意为“猫”，因此也被称为“猫城”。砂拉越河穿城而过，河畔的古老街区和横跨两岸的达鲁哈纳黄金桥，构成了城市最核心的景观。河滨公园、猫博物馆等地标，都曾见证Vera在此地的漫步与思索。

### 🌊 诗巫 (Sibu)：拉让江畔的文化熔炉

诗巫位于拉让江畔，是砂拉越的第三大城市。因其居民中华人比例极高且以福州人为主，这座城市又被称为“新福州”。拉让江是诗巫的生命线，繁忙的码头和中央市场充满了市井气息，是体验当地多元文化融合的绝佳窗口。

### 🏭 民都鲁 (Bintulu)：现代的工业脉搏

民都鲁是砂拉越主要的工业重镇，以石油、天然气和木材产业闻名。这座濒临南海的城市，是Vera在东马各个项目地点之间奔波穿行的真实写照，代表了沙捞越原始自然之外的另一面——一个充满现代工业脉搏、快速发展的区域。

### 🏔️ 京那巴鲁山 (Mount Kinabalu)：沉默的精神地标

京那巴鲁山位于沙巴，海拔4095米，是马来西亚和婆罗洲岛的最高峰。它被当地原住民尊为“神山”，是故事中最重要的精神象征之一。这座山在凯瑟琳（沙巴本地同行）的生活背景中占据核心地位，代表着一种沉默、永恒且坚韧的力量。关于神山，流传着一个动人的爱情故事：相传一位中国兄弟漂流至此，其妻子思念家乡而化为这座山峰，因此它又被称为“中国寡妇山”。这个关于坚守与等待的传说，与Vera在异乡的故事产生了跨越时空的共鸣。

### 🏝️ 哥打基纳巴卢 (Kota Kinabalu)：海风中的慰藉

哥打基纳巴卢是沙巴州的首府，华人社会惯称“亚庇”，英文简称KK。它西临南海，是Vera在沙巴出差时的据点，也是她从泥泞的工地抽身而出、短暂喘息的避风港。在这里，凯瑟琳会带她去海边的防波堤，那里不仅能看到壮丽的日落，更能感受到海风带来的片刻慰藉。

### 🚣 拉让江 (Rajang River)：贯穿故事的命运之河

拉让江是马来西亚最长的河流，全长约563公里，蜿蜒流经大半个砂拉越，最终汇入南中国海。这条浑浊而宽阔的大河，是故事中最重要的动态场景。Vera和她的团队乘坐长舟在江上奔走，引擎的轰鸣和雨季的泥泞构成了她工作日常的背景音。拉让江不仅是连接古晋、诗巫等城镇的交通要道，更是砂拉越文明的摇篮，见证了沿岸的雨林、长屋和悠久的部落文化。
