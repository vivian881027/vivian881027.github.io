## 五、分场视觉卡片示例（第17场·高潮剪枝）

### 【第17场视觉执行单】

| 项目 | 内容 |
|------|------|
| **场景** | 花店“岁时记”，深夜 |
| **时间** | 凌晨12:47 |
| **主色调** | 暖（吊灯）+ 暗部冷蓝（窗外） |
| **光线** | 单吊灯，水面反光（水桶），脸半明半暗 |
| **镜头序列** | 1.中景（两人对坐）→2.特写（速写画）→3.近景（林读字）→4.反打（苏）→5.侧面双人（走向山茶）→6.特写（手递剪刀）→7.特写（枯枝交界）→8.慢动作（剪刀咬合）→9.特写（落枝滚停）→10.特写（林的眼睛）→11.中景（苏捡枝）→12.近景（苏别枝）→13.特写（枯枝胸花）→14.远景（两人+影子）→15.叠化到软木板 |
| **声音** | 剪刀声（主）、水滴声、脚步声（轻）、第一次开口（沙哑）→无声 |
| **道具重点** | 山茶（三年老株）、剪刀（缠蓝布）、速写本、纸条 |
| **情绪标记** | 压抑→对峙→爆发（剪刀声）→释放（笑）→平静 |
| **备注** | 此场为全片核心，建议排练两周，一次性长镜头+穿插特写 |
