# “屿”香皂创业项目：完整流程顺序与预算

以下是从0到1创立“屿”品牌并完成首批产品上线的完整流程，按时间顺序排列，附带各阶段预算估算。

## 二、分阶段详细流程

### 第一阶段：市场调研与品牌定位（第1-2周）

**目标**：确认产品方向和品牌定位

| 序号 | 任务 | 具体内容 | 耗时 | 预算 |
| :--- | :--- | :--- | :--- | :--- |
| 1.1 | 竞品分析 | 研究Lush、观夏、Aesop、Buly等品牌 | 3天 | ¥0 |
| 1.2 | 目标用户访谈 | 访谈10-20位潜在用户（线上/线下） | 3天 | ¥500（礼品） |
| 1.3 | 确定品牌定位 | 品牌名、口号、核心叙事、目标客群 | 2天 | ¥0 |
| 1.4 | 确定产品线 | 首批SKU数量（建议3款）、香型方向 | 2天 | ¥0 |
| 1.5 | 注册公司 | 营业执照、商标查询（先查后注） | 4天 | ¥500-1,000 |
| 1.6 | 商标注册 | 提交商标申请（第3类） | 当天提交 | ¥1,500（官费） |

**第一阶段合计**：约 ¥2,000-3,000

**交付物**：
- 品牌定位书
- 竞品分析报告
- 产品规划文档
- 营业执照
- 商标受理通知书


### 第二阶段：产品研发与打样（第3-6周）

**目标**：完成配方开发，拿到可用样品

| 序号 | 任务 | 具体内容 | 耗时 | 预算 |
| :--- | :--- | :--- | :--- | :--- |
| 2.1 | 寻找OEM代工厂 | 线上搜索+实地考察（广州/义乌/上海） | 5天 | ¥1,000（差旅） |
| 2.2 | 签订保密协议+打样合同 | 明确配方要求（冷杉基底、起泡延迟、膜感） | 2天 | ¥0 |
| 2.3 | 第一轮打样 | 工厂按配方要求做3-5个样品 | 7-10天 | ¥3,000-5,000 |
| 2.4 | 样品测试 | 内部测试+10人用户测试 | 3天 | ¥500（用户礼品） |
| 2.5 | 第二轮打样 | 根据反馈调整配方 | 7天 | ¥2,000-3,000 |
| 2.6 | 第三轮打样（如需） | 精细调整 | 7天 | ¥2,000 |
| 2.7 | 确认配方 | 定型，确定生产工艺参数 | 2天 | ¥0 |
| 2.8 | 签订生产合同 | 明确价格、起订量、交付周期 | 2天 | ¥0 |

**第二阶段合计**：约 ¥8,500-11,500（含差旅）

**交付物**：
- 确认的配方文档
- 3-5块成品样品
- 生产合同


### 第三阶段：合规备案（第7-8周）

**目标**：完成化妆品备案，合法销售

| 序号 | 任务 | 具体内容 | 耗时 | 预算 |
| :--- | :--- | :--- | :--- | :--- |
| 3.1 | 产品检测 | 送第三方检测机构（微生物+重金属） | 5-7天 | ¥2,000-3,000 |
| 3.2 | 编写备案资料 | 配方、工艺、包装标签、安全评估 | 3天 | ¥0（自行编写） |
| 3.3 | 提交化妆品备案 | 通过“化妆品注册备案平台”提交 | 2天 | ¥0 |
| 3.4 | 等待备案通过 | 审核周期10-20个工作日 | 10-20天 | ¥0 |
| 3.5 | 备案后检查 | 如需补充资料，继续跟进 | — | ¥0 |
| 3.6 | 产品条形码 | 申请商品条形码（中国物品编码中心） | 3天 | ¥1,000-2,000 |
| 3.7 | 产品责任险 | 建议购买，降低风险 | 1天 | ¥2,000-3,000/年 |

**第三阶段合计**：约 ¥5,000-8,000

**交付物**：
- 检测报告
- 化妆品备案凭证
- 商品条形码


### 第四阶段：品牌视觉与物料设计（第9-12周）

**目标**：完成品牌识别系统和包装设计

| 序号 | 任务 | 具体内容 | 耗时 | 预算 |
| :--- | :--- | :--- | :--- | :--- |
| 4.1 | Logo设计 | 委托设计师或使用AI工具 | 5-7天 | ¥1,000-3,000 |
| 4.2 | 品牌视觉规范 | 色彩、字体、版式、摄影风格 | 3天 | ¥1,000-2,000 |
| 4.3 | 包装设计 | 外盒、内袋、说明书、束口袋 | 7-10天 | ¥2,000-5,000 |
| 4.4 | SKU概念图 | 用Midjourney/DALL·E生成 | 2天 | ¥100-500 |
| 4.5 | 电商详情页设计 | 主图、详情页、商品卡 | 5天 | ¥2,000-4,000 |
| 4.6 | 社交媒体素材 | 小红书/抖音模板 | 3天 | ¥1,000-2,000 |
| 4.7 | 包装打样 | 制作包装实物样品 | 5-7天 | ¥1,000-2,000 |

**第四阶段合计**：约 ¥8,000-18,500

**交付物**：
- Logo+视觉规范手册
- 包装设计文件（可交付印刷）
- SKU概念图
- 电商详情页设计稿


### 第五阶段：首批生产（第13-16周）

**目标**：生产首批可销售产品

| 序号 | 任务 | 具体内容 | 耗时 | 预算 |
| :--- | :--- | :--- | :--- | :--- |
| 5.1 | 确定首批数量 | 建议300-500块/SKU，共900-1500块 | 1天 | — |
| 5.2 | 原料采购 | 工厂采购或自行采购 | 3-5天 | 包含在生产费中 |
| 5.3 | 生产排期 | 与工厂确认生产时间 | 1天 | — |
| 5.4 | 生产执行 | 工厂生产+熟成（4-6周） | 4-6周 | ¥20,000-35,000 |
| 5.5 | 生产跟单 | 抽检、验货 | 2天 | ¥500-1,000（差旅） |
| 5.6 | 包装印刷 | 外盒、说明书等 | 7-10天 | ¥3,000-5,000 |
| 5.7 | 成品入库 | 打包、运输到仓库 | 3天 | ¥1,000-2,000 |

**单块成本估算**：
| SKU | 单块成本（含原料+生产+包装） |

### 第六阶段：包装与仓储（第17-18周）

## 五、省钱策略（如何降低预算）

| 策略 | 可节省 | 代价 |
| :--- | :--- | :--- |
| 自己完成品牌定位和设计（不用外部设计师） | ¥5,000-10,000 | 耗时，质量不确定 |
| 用AI生成SKU概念图和视频（代替专业拍摄） | ¥5,000-15,000 | 质感略弱 |
| 首批只做1款SKU（而不是3款） | ¥10,000-15,000 | 产品线单一 |
| 首批只做300块（而不是1000块） | ¥10,000-15,000 | 单块成本上升 |
| 不注册公司，先以个人名义试水 | ¥1,500 | 无法入驻电商平台 |
| 自宅作为仓库（不租仓库） | ¥1,000-2,000/月 | 空间有限 |
| 自己运营社交媒体（不投流） | ¥5,000-10,000 | 涨粉慢 |

**极限低成本方案**（约 ¥25,000-35,000）：
1. 只做1款SKU，300块
2. 自己完成品牌设计
3. AI生成所有视觉物料
4. 只用小红书店铺
5. 自宅发货

## 七、风险提示

| 风险 | 可能性 | 应对措施 |
| :--- | :--- | :--- |

| 产品不符合预期 | 中 | 多轮打样，找3家工厂对比 |
| 销售不及预期 | 高 | 首批少做（300-500块），验证后再加单 |
| 竞品出现 | 中 | 建立冷杉基底+仪式感的差异化 |
| 成本超支 | 中 | 每阶段设预算上限，严格把控 |
| 快闪店亏损 | 高 | 先线上验证，再考虑线下 |
