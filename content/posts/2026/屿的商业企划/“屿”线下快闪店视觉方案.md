# “屿”线下快闪店视觉方案

**版本**：V1.0  
**日期**：2026年4月  
**适用场景**：高端商场中庭/限时店、买手店合作空间、艺术市集  
**快闪店名称**：登岛  
**时长建议**：7-30天


## 一、核心概念

### 空间叙事
> 走进一座岛。不是离开城市，是在城市里开辟一座只属于你的孤岛。

### 关键词
侘寂、未完成、湿润、清冷、雾、岩石、苔藓、水、光

### 体验目标
- 第1秒：视觉安静下来
- 第10秒：闻到冷杉基底香
- 第30秒：触摸皂体，感受重量和颗粒
- 第60秒：完成“登岛仪式”小体验
- 离开时：带走一块皂，和一种“想回来”的感觉

### 各区域详细设计

#### 区域1：雾墙（入口）
| 要素 | 设计 |
| :--- | :--- |
| 功能 | 切换状态：从“商场”到“屿” |
| 视觉 | 半透明亚克力/磨砂玻璃墙，背后打冷光 |
| 嗅觉 | 干冰/加湿器 + 冷杉+乳香精油扩散（浓度：明显但不刺鼻） |
| 听觉 | 海浪声 + 雨声（极低音量，像背景白噪音） |
| 文字 | 墙面投影或蚀刻：“你到了。” |

#### 区域2：触摸岛（皂体陈列）
| 要素 | 设计 |
| :--- | :--- |
| 陈列台 | 未上釉深灰陶瓷托盘 + 粗糙木板 + 亚麻布垫 |
| 皂体陈列 | 每款3-5块，裸露摆放（无包装），允许触摸 |
| 高度 | 90cm（站立舒适触摸） |
| 灯光 | 顶部冷光射灯，45度角打光，强调纹理 |
| 辅助道具 | 每块皂旁放一块同色小岩石（呼应） |
| 说明牌 | 水洗牛皮纸，手写感字体，只写皂名和一句话叙事 |

#### 区域3：闻香岛（嗅觉体验）
| 要素 | 设计 |
| :--- | :--- |
| 功能 | 不接触皂体，直接闻“屿的嗅觉指纹” |
| 道具 | 未上釉陶瓷片（5×5cm），每片滴1滴冷杉基底精油 |
| 排列 | 挂在粗糙木板上，或放在小陶瓷碟中 |
| 说明 | “这是屿的嗅觉坐标。冷杉。所有味道都栖息在这片森林之上。” |
| 补充 | 旁边放三款SKU的主调精油小瓶（可单独闻） |

#### 区域4：仪式岛（体验区）
| 要素 | 设计 |
| :--- | :--- |
| 功能 | 用户亲自体验“登岛仪式” |
| 设施 | 小型洗手台（2-3个水龙头），深灰色岩石质感台面 |
| 道具 | 每台配：一块体验皂、打泡网、亚麻擦手巾、陶瓷皂托 |
| 流程 | 1. 湿手 2. 搓揉10秒 3. 观察泡沫 4. 冲洗 5. 擦干后感受膜感 |
| 引导牌 | 印在台面或墙面：“请用打泡网，或掌心快速搓揉10次——这是你的登岛仪式。” |
| 时长 | 每人体验约1分钟，排队时可先逛其他区域 |

#### 区域5：收银岛
| 要素 | 设计 |
| :--- | :--- |
| 台面 | 未上釉陶瓷 + 深色木材 |
| 陈列 | 所有SKU成品（带包装）+ 艺术家联名皂托 + 身体磨砂/身体霜 |
| 季节限定 | 单独小展台，配倒计时牌：“融雪 · 仅剩X天” |
| 包装 | 现场用亚麻束口袋 + 水洗牛皮纸盒包装 |
| 赠品 | 消费满300元送试香纸（浸冷杉基底油） |

#### 区域6：离岛通道
| 要素 | 设计 |
| :--- | :--- |
| 功能 | 离开前的最后一个触点 |
| 墙面 | 一整面镜子，镜面蚀刻或贴字：“你还在你的屿上。” |
| 补充 | 旁边可放一个“下次登岛”日历（用户可盖日期章） |

## 四、感官触点设计

### 嗅觉
| 位置 | 气味 | 浓度 |
| :--- | :--- | :--- |
| 雾墙（入口） | 冷杉+乳香（基底） | 高（明显） |
| 触摸岛 | 无额外扩香（皂体自然散发） | 中 |
| 闻香岛 | 陶瓷片上的基底精油 | 可近距离闻 |
| 仪式岛 | 皂体遇水后挥发 | 中高（湿润时） |
| 收银岛 | 轻微冷杉味 | 低 |

### 听觉
| 位置 | 声音 | 音量 |
| :--- | :--- | :--- |
| 全空间 | 海浪声 + 雨声（循环） | 35-40dB（背景） |
| 仪式岛 | 水龙头流水声（真实） | 自然 |
| 雾墙 | 干冰/加湿器微弱嗡声 | 可忽略 |

### 触觉
| 触点 | 材质触感 |
| :--- | :--- |
| 皂体 | 微凉、厚重、表面有颗粒感 |
| 陶瓷片 | 粗糙、吸水 |
| 木板 | 干燥、有木纹纹理 |
| 亚麻布 | 粗糙、柔软 |
| 水 | 温水（35-38℃） |

### 视觉
| 要素 | 设计 |
| :--- | :--- |
| 主光源 | 冷光射灯（3000-4000K），45度角 |
| 辅助光源 | 地面向上打光的洗墙灯（暖光极弱） |
| 阴影 | 保留自然阴影，不补平光 |
| 色彩 | 低饱和、斑驳、不完美 |
| 动态元素 | 雾墙的“雾”缓慢流动 |

## 六、人员配置

| 角色 | 人数 | 职责 |
| :--- | :--- | :--- |
| 店长 | 1 | 整体运营、库存管理 |
| 导购（屿使） | 2-3 | 引导体验、讲解品牌、协助仪式 |
| 收银 | 1 | 收银、包装 |
| 清洁维护 | 1（可兼职） | 保持皂体整洁、补充体验皂、擦干台面 |

**导购话术要点**：
- 不主动推销，先邀请体验
- 标准话术：“要试试登岛仪式吗？只要一分钟。”
- 不评价气味（“这个味道很好闻”改为“冷杉是屿的嗅觉坐标”）
- 离开时说：“下次再来岛上。”而不是“欢迎下次光临”

## 九、执行清单

### 筹备期（4-6周前）
- [ ] 确定场地（商场中庭/买手店/艺术空间）
- [ ] 签订租赁合同
- [ ] 确定搭建供应商
- [ ] 确定道具供应商（陶瓷、木板、亚麻）
- [ ] 设计说明牌、价格牌（水洗牛皮纸）

### 搭建期（2-3天前）
- [ ] 空间搭建（墙面、台面、洗手台）
- [ ] 灯光音响安装调试
- [ ] 道具摆放
- [ ] 皂体陈列（提前1天拆包装）

### 运营期（每日）
- [ ] 早：补充体验皂、擦干台面、检查精油扩香
- [ ] 中：补货、清洁
- [ ] 晚：盘点、清洁、记录销售数据

### 撤展期（最后1天）
- [ ] 剩余产品打包
- [ ] 道具回收（陶瓷皂托、亚麻布等可重复使用）
- [ ] 空间拆除


## 十、视觉参考图（文字描述）

### 参考风格
- 类似Aesop店铺的克制 + Le Labo的工业感 + 日本侘寂美学的“未完成”
- 可搜索关键词：“侘寂风店铺”、“Aesop店面设计”、“混凝土+木材+陶瓷”、“冷淡风快闪店”

### 色调参考
- 墙面：浅灰水泥或未刷漆的木板
- 台面：深灰岩石或未上釉陶瓷
- 道具：亚麻色、苔绿色、海盐白

### 可参考的艺术家/风格
- 彼得·卒姆托（Peter Zumthor）—— 瓦尔斯温泉浴场（岩石、水、光）
-  Axel Vervoordt —— 侘寂室内设计
-  Aesop 京都店 —— 暖帘+铜+陶瓷
