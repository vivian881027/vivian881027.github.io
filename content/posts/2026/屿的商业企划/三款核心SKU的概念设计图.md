## SKU 01：雨林与海

### 一句话卖点
> 太平洋西北海岸的雨天。冷杉与海盐的深呼吸。

### 皂体设计
| 要素 | 描述 |
| :--- | :--- |
| 主色调 | 墨绿（60%）、灰白（30%）、深灰（10%） |
| 纹理 | 大理石纹，墨绿与灰白不规则混合，像海浪冲刷岩石的痕迹 |
| 形状 | 圆角方块，边缘轻微不平整（手工切割感） |
| 表面 | 可见细小深绿色海藻碎颗粒（0.5-1mm） |
| 尺寸 | 8×6×3cm，120g |

### 拍摄场景（用于品牌宣传）
| 场景 | 描述 |
| :--- | :--- |
| 主图 | 皂体放在湿漉漉的深灰色岩石上，背景虚化的海浪和雾气，冷调光线 |
| 细节图 | 微距拍摄皂体表面纹理，海藻碎颗粒可见，水珠凝结在表面 |
| 使用图 | 双手合握皂体，乳霜状白色泡沫从指缝溢出，深色背景 |
| 氛围图 | 浴室窗台，皂体旁放一枝冷杉枝叶，窗外虚化的雨景 |

### 情绪关键词
湿润、清冷、孤寂、深呼吸、海洋、森林边缘

### AI绘图提示词（可直接复制）
```
A handcrafted soap bar, 8x6x3cm, rounded square shape with slightly uneven hand-cut edges. Color: deep muted green (60%) mixed with off-white (30%) marble pattern, resembling waves washing over rocks. Tiny visible dark green seaweed flakes embedded on surface. Placed on wet dark grey coastal rock, background blurred ocean waves and mist. Cold natural lighting, moody atmosphere, cinematic, 8K. No text, no logo, photorealistic. --ar 4:3
```


## SKU 02：地衣与火

### 一句话卖点
> 深秋夜晚，地衣覆盖的倒木旁，快要熄灭的篝火。

### 皂体设计
| 要素 | 描述 |
| :--- | :--- |
| 主色调 | 灰绿（70%）、暗橙（20%）、深灰（10%） |
| 纹理 | 灰绿基底上分布暗橙色点状或细线状斑点，像篝火余烬 |
| 形状 | 圆角方块，边缘轻微不平整 |
| 表面 | 可见细小火山石粉末颗粒（深灰色，0.3-0.8mm），轻微磨砂触感 |
| 尺寸 | 8×6×3cm，120g |

### 拍摄场景（用于品牌宣传）
| 场景 | 描述 |
| :--- | :--- |
| 主图 | 皂体放在深色木板上，旁边是熄灭的篝火残烬（灰烬、焦木），暗调暖光 |
| 细节图 | 微距拍摄暗橙色斑点，像火星余烬，表面颗粒感可见 |
| 使用图 | 泡沫在深色皮肤/背景上，泡沫呈乳霜状，温暖的光晕 |
| 氛围图 | 浴室一角，皂体放在未上釉深灰陶瓷皂托上，旁边一根烧焦的树枝 |

### 情绪关键词
余温、内省、烟熏、安静、深秋、篝火残烬

### AI绘图提示词
```
A handcrafted soap bar, 8x6x3cm, rounded square shape with slightly uneven edges. Color: muted grey-green base (70%) with scattered small burnt orange speckles and thin lines (20%), resembling dying embers of a campfire. Tiny dark grey volcanic rock powder particles visible on surface, subtle texture. Placed on dark weathered wood plank next to ash and charcoal pieces. Warm low-key lighting, moody, autumn evening atmosphere, cinematic, photorealistic. No text, no logo. --ar 4:3
```


## SKU 03：融雪（季节限定）

### 一句话卖点
> 冬天结束前的最后一场冷。雪化了，泥土第一次露出来。

### 皂体设计
| 要素 | 描述 |
| :--- | :--- |
| 主色调 | 半透明白（80%）、浅灰（15%）、深褐（5%） |
| 纹理 | 白色基底略带半透明感，像即将融化的雪；表面有深褐色细小颗粒（模拟泥土/枯叶碎） |
| 形状 | 圆角方块，边缘轻微不平整 |
| 表面 | 可见燕麦片碎粒（浅米色）和深褐色细小植物颗粒，像雪下的泥土 |
| 尺寸 | 8×6×3cm，120g |
| 特殊效果 | 皂体边缘略薄，像被“融化”过（手工修边） |

### 拍摄场景（用于品牌宣传）
| 场景 | 描述 |
| :--- | :--- |
| 主图 | 皂体放在融雪的水洼边，背景是残留的雪和裸露的泥土，冷调晨光 |
| 细节图 | 微距拍摄半透明皂体，可见内部的深色颗粒，像雪下的世界 |
| 使用图 | 白色乳霜泡沫，泡沫中隐约可见深色细小颗粒 |
| 氛围图 | 窗台，皂体旁有一小枝紫罗兰（呼应紫罗兰香调），窗外雪景 |

### 情绪关键词
融雪、泥土、短暂、清冷、等待、冬天结束

### AI绘图提示词
```
A handcrafted soap bar, 8x6x3cm, rounded square shape with slightly uneven edges, corners appear slightly melted. Color: semi-translucent white (80%) with subtle light grey marbling, like melting snow. Tiny dark brown particles (simulating soil and dead leaf fragments) and light beige oat flakes visible throughout. Placed in a shallow puddle of meltwater on wet earth, background out-of-focus patches of remaining snow and muddy ground. Cold morning light, slightly melancholic, late winter atmosphere, photorealistic, cinematic. No text, no logo. --ar 4:3
```


## 三款SKU合影（全家福）设计

### 场景描述
三块皂并排放置在**未上釉的深灰色陶瓷托盘**上，背景是雾蒙蒙的森林/海岸。光线从左侧自然光进入，右侧略暗。

### 排列顺序（从左到右）
雨林与海（墨绿） → 地衣与火（灰绿+橙） → 融雪（半透明白）

### AI绘图提示词（全家福）
```
Three handcrafted soap bars arranged side by side on a rough unglazed dark grey ceramic tray. From left to right: 1) Deep muted green with off-white marble pattern and seaweed flakes; 2) Muted grey-green with burnt orange speckles; 3) Semi-translucent white with dark brown particles. Background: misty forest and distant ocean, soft natural light from left, moody and calm atmosphere. Cinematic, 8K, product photography style. No text, no logo. --ar 16:9
```


## 品牌视觉统一原则（给设计师的补充）

| 原则 | 说明 |
| :--- | :--- |
| 不要 | 高饱和色、荧光色、光滑塑料感、纯白背景、过度PS |
| 要 | 低饱和、自然材质（岩石、木头、亚麻、陶）、可见手工痕迹、真实水汽/雾气 |
| 光线 | 优先自然光，冷调或中性调，避免暖黄光（除非地衣与火可用暖光） |
| 构图 | 留白充足，给文字留空间；皂体为主角，不喧宾夺主 |
| 氛围词 | 安静、克制、侘寂、湿润、清冷、呼吸感 |
