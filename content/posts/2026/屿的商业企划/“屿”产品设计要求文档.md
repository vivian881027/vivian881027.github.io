# “屿”产品设计要求文档

**版本**：V1.0  
**日期**：2026年4月  
**密级**：保密（仅限OEM代工厂及内部研发）  
**适用产品**：屿 手工香皂（核心产品线及季节限定）


## 一、文档目的

本文档用于指导OEM代工厂生产符合“屿”品牌定位的手工香皂。所有参数均为**强制要求**，偏离需经品牌方书面确认。

**核心原则**：
> 屿不卖清洁功能。屿卖的是：冷杉嗅觉指纹 × 起泡仪式感 × 皮肤膜感叙事。  
> 以下所有参数服务于这三大体验锚点。


## 二、基础配方架构

### 2.1 油脂基底（冷制皂工艺）

| 成分 | 比例 | 功能 |
| :--- | :--- | :--- |
| 橄榄油 | 40% | 基底油，提供滋润感和保湿膜感 |
| 椰子油 | 20% | 起泡力来源（但需控制，避免过度起泡） |
| 乳木果油 | 15% | 增加膏体硬度，提供成膜感 |
| 可可脂 | 10% | 增强皮肤残留膜感 |
| 杏核油 | 10% | 轻盈感，平衡厚重 |
| 蓖麻油 | 5% | 稳定泡沫，增加稠度 |

**关键要求**：
- 椰子油比例**不得超过20%**，否则起泡过快过大，破坏“起泡延迟”设计
- 乳木果油 + 可可脂总比例**不低于25%**，确保洗后膜感

### 2.2 水相

| 成分 | 要求 |
| :--- | :--- |
| 基础水相 | 蒸馏水或植物纯露（推荐：冷杉纯露或岩玫瑰纯露） |
| 减碱 | 减碱5%-8%（降低游离碱，增强温和度和膜感） |

**关键要求**：
- 必须减碱。标准制皂减碱0%-3%，“屿”要求**5%-8%**，以保留更多未皂化油脂，形成皮肤膜感


## 三、核心体验参数

### 3.1 冷杉基底浓度（嗅觉指纹）

**目标**：所有产品（无论主调是什么）都能闻到一致的冷杉+乳香基底味

| 参数 | 要求 |
| :--- | :--- |
| **冷杉精油** | 占配方总精油量的**40%-50%**（固定值，不随主调变化） |
| **乳香精油** | 占配方总精油量的**15%-20%**（固定值） |
| **主调精油** | 占配方总精油量的**30%-45%**（视具体SKU调整） |
| **总精油添加量** | 皂液总重量的**3%-5%**（高于行业平均2%，确保留香） |

**操作说明**：
- 每批次生产前，先按固定比例配制“屿基底精油”（冷杉:乳香 = 70:30 体积比）
- 基底精油占最终精油混合物的**60%-65%**
- 主调精油（如海盐、苔藓、紫罗兰）占**35%-40%**

**验证方法**：
- 成品皂化熟成后（4-6周），由3名以上测试员闻香
- 必须能清晰辨识冷杉基底味，且冷杉味与主调味比例约为**6:4**
- 冷杉味不得被主调完全掩盖

**常见问题**：
> 冷杉精油在皂化过程中会挥发一部分。建议在**轻T（轻度稠化）** 时加入精油，且皂化温度控制在**35-40℃**，避免高温导致挥发。

### 3.2 起泡延迟参数（仪式感）

**目标**：用户需要主动搓揉10秒以上，才能产生浓密的乳霜状泡沫

| 参数 | 要求 |
| :--- | :--- |
| **起泡延迟时间** | 双手干搓（无水条件下）需**8-12秒**才出现明显泡沫 |
| **泡沫密度** | 泡沫应为**小泡、绵密、乳霜状**，非大泡、蓬松状 |
| **泡沫量** | 中等（不追求大量泡沫） |
| **椰子油比例上限** | **20%**（超过会起泡过快） |
| **硬脂酸添加** | **禁止添加**硬脂酸或起泡剂（如SLS/SLES） |

**操作说明**：
- 通过降低椰子油比例 + 提高乳木果油/可可脂来实现延迟起泡
- 如需微调，可添加**0.5%-1% 蜂蜡**进一步抑制起泡速度

**验证方法**：
- 25℃室温下，测试员双手打湿，取皂搓揉
- 计时从开始搓揉到出现明显乳霜状泡沫
- 要求：**8-12秒**（允许±1秒误差）
- 泡沫置于黑色背景上观察：应为白色不透明、细小气泡

**常见问题**：
> 用户反馈“不起泡”是预期内的。需在包装上说明“搓揉10次”的仪式指引。如用户仍抱怨，可附赠打泡网。

### 3.3 皮肤膜感参数（叙事延续）

**目标**：洗后皮肤留下微滑、微保湿的膜感，持续15-30分钟

| 参数 | 要求 |
| :--- | :--- |
| **膜感强度** | 洗后擦干，皮肤表面应有**可感知的滑感**（非油腻） |
| **膜感持续时间** | 自然状态下（不涂身体乳）持续**15-30分钟** |
| **油脂残留量** | 通过减碱5%-8% + 高比例乳木果油/可可脂实现 |
| **添加物** | 可添加**0.5%-1% 海藻提取物**或**燕麦胶体**增强成膜感 |

**操作说明**：
- 不追求“涩手=干净”的传统肤感
- 膜感应是“清爽的滑”，而非“油腻的滑”
- 如测试中感觉油腻，可降低可可脂比例、增加杏核油

**验证方法**：
- 清洗后擦干，5分钟后由测试员自评肤感（1-5分，4分为目标）
- 20分钟后再次评估，应仍有轻微滑感
- 用透明胶带贴皮肤后撕下，观察皮脂残留量（定性即可）

**常见问题**：
> 用户可能误以为“没洗干净”。需在包装和详情页教育：“这不是残留，是你的‘皮肤海盐壳’。”


## 四、物理规格

### 4.1 皂体尺寸

| 参数 | 要求 | 公差 |
| :--- | :--- | :--- |
| 长度 | 80mm | ±2mm |
| 宽度 | 60mm | ±2mm |
| 高度 | 30mm | ±2mm |
| 重量 | 120g | ±5g |
| 形状 | 圆角方块（类似河卵石） | 四角R角8-10mm |

**关键要求**：
- 边缘**不得过于规整**，需保留手工切割的轻微不平整感
- 表面可保留轻微的手工痕迹（非模具压制的完美光滑）

### 4.2 视觉纹理

| SKU | 主色 | 纹理要求 |
| :--- | :--- | :--- |
| 雨林与海 | 墨绿 + 灰白 | 大理石纹，不规则混合，无固定图案 |
| 地衣与火 | 灰绿 + 暗橙斑点 | 灰绿基底，暗橙色点状或细线状分布 |
| 融雪 | 半透明白 + 深色细点 | 白色基底略带透明感，表面有深色细小颗粒 |

**通用要求**：
- 色彩饱和度为**低饱和**（禁止荧光色、高饱和色）
- 允许色差——每块皂颜色略有不同是可接受的（“手工感”）

### 4.3 添加物（视觉与触感）

| 添加物 | SKU | 要求 |
| :--- | :--- | :--- |
| 海藻碎 | 雨林与海 | 0.5%-1%，可见但不过密 |
| 火山石粉末 | 地衣与火 | 1%-2%，提供细微颗粒感 |
| 燕麦片 | 融雪 | 0.5%-1%，细小碎片 |
| 矿物粉（天然色素） | 所有 | 仅使用天然矿物色素（云母、氧化铁、绿泥石等） |


## 五、生产流程要求

### 5.1 温度控制

| 环节 | 温度要求 |
| :--- | :--- |
| 油碱混合 | 35-40℃ |
| 精油添加 | 轻T阶段（35-38℃） |
| 入模后保温 | 24-30℃，48小时 |
| 切割时机 | 入模后48-72小时 |

### 5.2 熟成（皂化）时间

| 要求 | 说明 |
| :--- | :--- |
| 最小熟成时间 | **4周**（28天） |
| 推荐熟成时间 | **6周**（42天）——pH值更低，膜感更优 |
| 熟成环境 | 通风、避光、温度20-25℃，湿度<60% |

### 5.3 品控抽检

| 检测项 | 频率 | 接受标准 |
| :--- | :--- | :--- |
| 起泡延迟时间 | 每批次3块 | 8-12秒 |
| 膜感评估 | 每批次3块 | 5分钟滑感≥4/5 |
| 冷杉气味强度 | 每批次3块 | 冷杉基底清晰可辨 |
| pH值 | 每批次3块 | 7.5-9.0（冷制皂正常范围） |
| 重量 | 每批次10% | 115-125g |


## 六、包装与标识要求

### 6.1 皂体标识

- **不直接印logo在皂体上**（保持自然感）
- 可用**可食用色粉**在侧面点一个小点表示批次（可选）

### 6.2 内包装

- 亚麻束口袋（品牌方提供或指定供应商）
- 每块皂独立装袋

### 6.3 外包装盒

- 水洗牛皮纸，品牌方提供设计稿
- 每盒内置一张棉纸说明书（正面“登岛仪式”，背面故事）

### 6.4 批次追溯

- 在外盒底部贴小标签：生产日期、批次号、有效期（2年）


## 七、常见问题与拒绝标准

| 问题 | 处理 |
| :--- | :--- |
| 椰子油比例 >20% | **拒收** |
| 起泡延迟 <6秒 | **拒收** |
| 膜感评分 <3/5 | 批次降级，需重新调整配方 |
| 冷杉基底味不可辨 | **拒收** |
| 添加人工色素或SLS | **拒收**，终止合作 |
| 重量 <115g | 补发或折价，但批次超标则拒收 |
| pH >10 | 延长熟成时间，复检合格后发货 |

- 品牌方每轮提供书面反馈
