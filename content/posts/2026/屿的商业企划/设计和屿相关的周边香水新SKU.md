## 考虑到沐浴露和润肤露和香皂更加配套，设计和屿相关的周边沐浴露+润肤露新SKU 白桦树系列 以及瓶身造型

基于“白桦树”系列的核心理念（清冽、温柔、扎根、智性），将洗浴产品设计为“从清洁到滋养”的完整仪式，恰好对应了故事中“看见他、承接他、成为他的大地”的情感逻辑。

以下是专为**香皂屿·白桦树系列**设计的沐浴露与润肤露SKU，与之前构思的香水完美配套，形成从浴室到衣橱的完整香氛叙事。

### 系列定位：白桦树·晨间与夜色
**核心概念**：沐浴露是“清晨站在白桦树下的第一阵风”，润肤露则是“夜晚靠在他白衬衫胸口的体温”。

## 🧴 SKU 1：白桦树·清冽晨雾 (沐浴露)
**英文名**：Birch · Morning Mist

### 香调对应
与香水“初雪枝”同香，但更强调**洁净感与水汽感**，突出“干净、清朗、挺拔”的晨间意象。

- **前调**（开瓶清新）：日本柚子、青柠、白松香、微量海洋调（模拟晨间露水与冷空气）
- **中调**（洗浴中散发）：白桦叶、绿茶、无花果奶液（保留那抹标志性的自然奶香，更轻盈）
- **后调**（浴后留香）：白麝香、雪松、香根草（轻柔贴肤，像他刚洗完澡穿上浴袍的味道）

### 质地与使用感
- **透明啫喱质地**，起泡细腻但不丰盈（强调“干净不假滑”的处女座式克制）。
- 洗后肤感**清爽微涩**，如同被晨风吹过，无需立即涂润肤露也不会紧绷。

### 瓶身造型设计
呼应“白桦树干”意象，与香水瓶同系列但更实用：

| 设计元素 | 具体描述 |
| :--- | :--- |
| **瓶身形状** | 修长圆柱形，**上宽下窄**（便于倒置使用），线条笔直如白桦树干。 |
| **材质** | **磨砂半透明白色玻璃**（能看到液体流动，但朦胧如雾气）。 |
| **瓶盖** | **浅灰色哑光软胶泵头**，按压处有细微树皮纹理防滑，触感温润。 |
| **装饰** | 瓶身正面以**银白色线条**蚀刻一株简约的白桦树（树干+几片叶子）。 |
| **容量** | 300ml / 500ml，瓶身修长适合手握。 |

### 故事卡文案
> *“清晨六点半，他穿着浴袍推开浴室门，带出一阵冷空气与白桦叶的香气。你没有睁眼，但你知道——新的一天，是从他的干净开始的。”*

## 🧴 SKU 2：白桦树·温柔根际 (润肤露)
**英文名**：Birch · Gentle Root

### 香调对应
与香水“暖根处”同香，但更强调**包裹感与延展性**，突出“扎根大地、温柔可靠、体温呵护”的夜晚意象。

- **前调**（挤出瞬间）：小豆蔻、胡萝卜籽、燕麦奶（微甜谷物气息，模拟“根部土壤”的踏实感）
- **中调**（涂抹中释放）：鸢尾花、大米、婴儿爽身粉、檀木醇（标志性的“洁净体香”核心）
- **后调**（持久留香）：龙涎香醚、开司米酮（模拟体温）、香草、白麝香（皮肤融合后，像被拥抱的温暖）

### 质地与使用感
- **乳霜质地**，介于乳液与霜之间，**延展性极佳**（一推即化，不粘腻）。
- 吸收后皮肤表面形成**哑光丝绒感**，而非油亮——如同他干净衬衫下，皮肤的柔润触感。
- **留香持久**：涂抹后4-6小时，贴近皮肤仍能闻到“体温下的奶香木质”。

### 瓶身造型设计
呼应“根系与拥抱”意象，与沐浴露形成“一竖一横”的视觉对比：

| 设计元素 | 具体描述 |
| :--- | :--- |
| **瓶身形状** | **宽肩扁圆瓶**，底部厚重，像一棵树的横截面。从上方看是椭圆形，手握舒适。 |
| **材质** | **奶白色陶瓷质感玻璃**（不透明，温润如玉），触感如婴儿皮肤。 |
| **瓶盖** | **浅灰木纹按压泵头**，泵嘴略短，避免按压时溅出。 |
| **装饰** | 瓶身正面以**浅金色线条**勾勒白桦树的根系（向下延伸的曲线），与沐浴露的“树干”形成对照。 |
| **容量** | 200ml / 400ml，扁圆瓶身适合放在浴室架或床头柜。 |

### 故事卡文案
> *“睡前，他把润肤露挤在手心焐热，再从你的肩膀涂抹到指尖。你说‘好香’，他说‘是你喜欢的味道’。其实那是他自己——是月亮巨蟹6宫，把温柔熬成根系的证明。”*

## 🧪 关于配方的特别说明（如果你真要落地）

1.  **沐浴露**：建议使用**氨基酸表活**（如月桂酰谷氨酸钠），洗后不干涩，且对“奶香”调性无干扰。避免SLS/SLES，太刺激会破坏“温柔”叙事。
2.  **润肤露**：必须加入**角鲨烷**和**少量燕麦仁油**，模拟“皮肤本身的脂质感”，让奶香更像是“从他皮肤里长出来的”，而非外加的香精。
3.  **共香技术**：沐浴露与润肤露的香精核心一致（白桦叶+无花果奶液+白麝香），但润肤露中增加**开司米酮**浓度，利用体温激活“体香感”。
4.  **防腐体系**：使用**对羟基苯乙酮+1,2-己二醇**（多元醇温和防腐），避免传统防腐剂的“化工感”，贴合“自然体香”的定位。
