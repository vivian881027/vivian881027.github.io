# 《夫人》章节编号系统说明

## 一、缩写含义

在《夫人》的场景编排与章节规划中，使用三个字母前缀标记不同的叙事时空：

| 前缀 | 全称 | 含义 | 时间范围 | 典型空间 |
| :--- | :--- | :--- | :--- | :--- |
| **P** | **Prison / Present** | 监狱现在时——叙事锚点 | 2028-2031年 | 监狱探视室、牢房 |
| **F** | **Flashback** | 闪回/记忆回溯 | 2003-2028年 | 华讯实验室、大学、精神病院、公益展场地 |
| **A** | **Action** | 行动/外部事件 | 2018-2028年 | 慈善晚宴、院长办公室、监控室、拍卖后台 |


## 二、P-63 与 P-65 的具体对应

| 编号 | 对应章节 | 标题 | 内容 |
| :--- | :--- | :--- | :--- |
| **P-63** | **第63章** | **积木** | 徐砚之带积木探视。她沉默地搭完城堡，不解释。灰蓝色信封被打开。 |
| **P-65** | **第65章** | **出狱倒计时** | 三年后出狱。阳光直接落在她脸上。徐砚之在监狱外等她。城市巨网在远方展开，精神病院屋顶仍在。开放终局。 |

**P-63 和 P-65 都属于“监狱现在时”时间线**——即故事中2028-2031年的监狱阶段。


## 三、编号系统的完整逻辑

### 3.1 编号规则

每个场景编号由 **前缀字母 + 章节号** 组成：

- **P-1** = 第1章（监狱现在时）
- **F-5** = 第5章（闪回/华讯）
- **A-21** = 第21章（行动/公益展）
- **P-49** = 第49章（监狱现在时/女儿探视）
- **F-51** = 第51章（闪回/华讯完整真相）
- **P-63** = 第63章（监狱现在时/积木）
- **P-65** = 第65章（监狱现在时/出狱）

### 3.2 为什么用前缀而不是纯章节号？

《夫人》采用**插叙结构**——同一章内可能同时包含“现在时”和“闪回/行动”。

前缀帮助在场景编排中**一眼识别时空归属**：

| 纯章节号 | 前缀编号 | 时空 | 功能 |
| :--- | :--- | :--- | :--- |
| 第1章 | P-1 | 现在时（监狱） | 开场/谜面建立 |
| 第5章 | F-5 | 过去时（华讯） | 华讯开端/蓝光建立 |
| 第21章 | A-21 | 过去时（公益展） | 进入第二幕 |
| 第31章 | A-31 | 过去时（精神病院） | 陈默首次出现 |
| 第49章 | P-49 | 现在时（监狱） | 灵魂黑夜/女儿探视 |
| 第51章 | F-51 | 过去时（华讯） | 完整真相/真实自我揭露 |
| 第63章 | P-63 | 现在时（监狱） | 积木/不翻译的胜利 |
| 第65章 | P-65 | 现在时（监狱外） | 出狱/开放终局 |

### 3.3 前缀与故事结构的关系

```
第一幕：现状·囚笼中的女院长（P为主，穿插F/A）
    ↓
第二幕：回溯·翻译者的诞生与系统建成（F/A为主，穿插P的对话间隙）
    ↓
第三幕：对决·监狱中的对峙与交付（P为主，穿插F/A的最终揭示）
```

**P = 骨架**（叙事锚点，读者始终知道她“现在”在哪里）
**F = 血肉**（创伤起源，解释她“为什么”变成这样）
**A = 肌肉**（外部行动，展示她“做了什么”）
